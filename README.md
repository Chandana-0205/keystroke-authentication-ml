# 🔐 Continuous Typing Authentication System using Keystroke Dynamics (CTAS-KD)

## 📌 Overview
The Continuous Typing Authentication System using Keystroke Dynamics (CTAS-KD) is a machine learning-based security system that authenticates users based on their typing behavior. Unlike traditional password-based systems, this project uses behavioral biometrics such as keystroke timing patterns to enhance security.

The system captures typing data, extracts features like dwell time and flight time, and uses a Random Forest Classifier to classify users as **Genuine** or **Imposter**.

---

## 🎯 Objectives
- To develop a machine learning-based authentication system
- To analyze typing behavior using keystroke dynamics
- To improve security beyond traditional password systems
- To provide fast and accurate real-time predictions

---

## ⚙️ Features
- ⌨️ Keystroke data capture (key press & release timing)
- 📊 Feature extraction (Dwell Time, Flight Time)
- 🤖 Machine Learning model (Random Forest Classifier)
- ⚡ Real-time authentication (Genuine / Imposter)
- 🔐 Behavioral biometric-based security
- 🧠 Efficient and accurate prediction system

---

## 🧩 System Workflow
1. User enters typing input
2. System captures keystroke timings
3. Features are extracted (dwell time & flight time)
4. Data is processed and sent to ML model
5. Model predicts user authenticity
6. Result is displayed (Genuine / Imposter)
